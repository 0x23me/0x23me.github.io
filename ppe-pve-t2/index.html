Proxmox VE kernels for T2 Macs.

Built from Proxmox's kernel source with the t2linux patches, and served as an APT repository at apt.0x23.me.

Install → Releases ↗

Version 7.0.14-30 · Proxmox VE 9 (Debian trixie), amd64

Install with APT
wget -qO /usr/share/keyrings/ppe-pve-t2.asc https://apt.0x23.me/KEY.gpg
echo "deb [signed-by=/usr/share/keyrings/ppe-pve-t2.asc] https://apt.0x23.me trixie main" > /etc/apt/sources.list.d/ppe-pve-t2.list
apt update && apt install proxmox-kernel-t2-7.0 proxmox-headers-t2-7.0

As root on the Proxmox host, then reboot. uname -r then ends in -pve-t2.

New T2 kernels arrive with a normal apt upgrade.

01 / What's in it

Proxmox's kernel with the t2linux patches.

01 · T2 HARDWARE

The t2linux patches add the drivers for the hardware behind the T2 chip: Touch Bar, BCE (Buffer Copy Engine), Bluetooth, and APFS.

02 · NEXT TO PROXMOX'S OWN

The packages are named with t2 (proxmox-kernel-t2-7.0), so they don't collide with Proxmox's own proxmox-kernel-7.0. Both can stay installed, no apt pinning needed.

03 · SIGNED

The repository is signed. The key's fingerprint is 47BEEF6A0CC800F7EB4A19C4C4F60CABCD494490.

02 / How it's built

Checked every day, built when something changed.

Every build is also a GitHub release with the packages.

  • checkLooks for a new tag in Proxmox's pve-kernel repository and new t2linux patches.
  • buildIn a debian:trixie container: pve-kernel at that tag, the t2linux patches, and T2.patch, which adds the -t2 suffix and turns on the T2 options.
  • publishAdds the packages to the repository with aptly, signs it and uploads it to apt.0x23.me.
