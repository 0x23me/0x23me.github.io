01 / Install

One tap for the Mac apps. One APT repository for the kernel.

The Mac apps are signed and notarized, and Homebrew keeps them up to date. The kernel comes from apt.0x23.me and updates with a normal apt upgrade.

Mac apps
brew tap 0x23me/tap
brew trust --cask 0x23me/tap/priel
brew install --cask 0x23me/tap/priel

The same two lines with pbs-mackup for PBS Mackup.

Proxmox T2 kernel
wget -qO /usr/share/keyrings/ppe-pve-t2.asc https://apt.0x23.me/KEY.gpg
echo "deb [signed-by=/usr/share/keyrings/ppe-pve-t2.asc] https://apt.0x23.me trixie main" > /etc/apt/sources.list.d/ppe-pve-t2.list
apt update && apt install proxmox-kernel-t2-7.0 proxmox-headers-t2-7.0

As root on the Proxmox host, then reboot. Details in the README.
